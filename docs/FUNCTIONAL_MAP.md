# Функциональная карта RTSC-Core

## Реализовано в текущем core

- регистрация и вход по email/password;
- bootstrap первого SuperAdmin;
- роли `User`, `Admin`, `SuperAdmin`;
- блокировка пользователей и смена ролей в админке;
- создание, редактирование и модерация сообществ;
- роли владельца и администратора сообщества;
- создание, редактирование и модерация мероприятий;
- публичная афиша и карточки мероприятий;
- регистрация и отмена регистрации участника;
- лимит вместимости и окно регистрации;
- управление участниками;
- статусы `Registered`, `Confirmed`, `Attended`, `Cancelled`, `NoShow`;
- назначение исполнителей мероприятия;
- персональный подписанный QR-билет;
- check-in организатором после сканирования QR обычной камерой телефона;
- завершение мероприятия;
- оценка исполнителя участником после фактического посещения;
- публичный рейтинг исполнителя по последним 20 мероприятиям;
- оценка участника организатором;
- комментарии к оценкам;
- первичный фильтр оскорбительных/нецензурных слов;
- очередь комментариев на ручную модерацию;
- публикация, скрытие и удаление комментариев в админке;
- единая админ-панель внутри основного приложения;
- Docker Compose: приложение + PostgreSQL;
- постоянное хранение Data Protection keys для QR и cookie crypto;
- GitHub Actions build workflow;
- smoke-check script.

## Следующий этап

- профиль пользователя и редактирование персональных данных;
- привязка `ExternalAccount`;
- единая система уведомлений;
- MAX как первый messenger adapter;
- затем VK и Telegram;
- календарь и карта мероприятий;
- экспорт участников и отчёты;
- импорт данных из RTSC-next;
- нормальные EF Core migrations вместо SQL bootstrap.

## После core parity

- достижения;
- промокоды;
- рефералы;
- магазин;
- история баллов/операций.

## Что намеренно не переносим из старой архитектуры

- отдельный пользовательский WASM host;
- отдельный admin WASM host;
- SharedWasm / SharedWeb;
- собственный Material3 C# wrapper;
- обязательный npm build для основного UI;
- Tailwind watcher;
- DevReverseProxy;
- SSE по умолчанию;
- отдельные action-request сущности под каждую разновидность модерации.
